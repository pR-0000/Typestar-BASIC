# Typestar BASIC 0.4.101-dev

[Français](#français) · [English](#english)

## Français

Cette version ajoute le déplacement de la tête d'impression au clavier, depuis le prompt BASIC :

| Touches | Action |
|---|---|
| CODE + LEFT MARGIN | Déplacer la tête vers la gauche. |
| CODE + RIGHT MARGIN | Déplacer la tête vers la droite. |

Le déplacement se répète pendant l'appui, par pas d'un caractère Courier 10. Relâcher l'une des touches arrête le mouvement. La feuille garde sa hauteur et la tête reste froide. Le programme, les variables et la ligne en cours sont conservés.

La prochaine impression LPRINT, LLIST ou graphique part de la position choisie. Un déplacement établit un nouveau repère pour les prochaines opérations papier. Les raccourcis fonctionnent au prompt BASIC ; les programmes et INPUT gardent leurs commandes habituelles. CODE + flèches continue de saisir `<` et `>` ; les touches de marge seules parcourent toujours l'historique.

Le suivi de position compte les phases réellement commandées, y compris HEAD et l'aller-retour d'approche du pilote Canon. La course des raccourcis couvre 72 pas depuis la position initiale. Un contrôle de la largeur complète de chaque bande, répétitions comprises, arrête une impression qui dépasserait la limite droite avec `?PAPER`. Choisissez une position laissant assez de place à votre dessin sur la feuille.

Le déplacement utilise le pilote moteur et sa réserve temporaire habituelle de 220 octets. La RAM BASIC libre à vide reste de 5 951 octets ; les 37 tokens et 54 commandes sont conservés. Studio **0.2.41** reconnaît cette ROM et conserve le même suivi en impression normale ou instantanée.

Cette version corrige aussi l'affichage de **RETURN sans GOSUB** : le message complet `?GOSUB/RETURN`, suivi du numéro de ligne, possède maintenant sa propre chaîne de caractères protégée dans la ROM. Les erreurs d'impression libèrent correctement l'état du pilote pour permettre un nouvel essai.

Le déplacement de la tête a été confirmé sur machine le **24 novembre 2026**. Les **17 rapports logiciels** passent sur le hash exact de cette version : exécution BASIC, mémoire, cinq démarrages avec la maskROM, transferts série, sons, graphismes, jeux et raccourcis clavier. Le nouveau contrôle couvre notamment 2 600 correspondances de touches et 64 transitions moteur, ainsi que le point de départ des impressions après RUN. Les [images, empreintes et rapports](../../firmware/0.4.101-dev/README.md) et les manuels PDF français/anglais accompagnent la publication.

## English

This version adds keyboard control of the print head from the BASIC prompt:

| Keys | Action |
|---|---|
| CODE + LEFT MARGIN | Move the head left. |
| CODE + RIGHT MARGIN | Move the head right. |

Movement repeats while the keys are held, one Courier 10 character pitch at a time. Releasing either key stops it. The paper stays at the same height and the head remains unheated. The program, variables and line being edited are preserved.

The next LPRINT, LLIST or graphic printout starts at the selected position. Moving the head establishes a new reference for subsequent paper operations. The shortcuts work at the BASIC prompt; programs and INPUT keep their usual controls. CODE + arrows still enters `<` and `>`; the margin keys alone still browse history.

Position tracking counts the phases actually commanded, including HEAD and the Canon driver's approach round trip. The shortcuts cover 72 pitches from the initial position. A check of each band's complete width, including repeats, stops a printout that would cross the right limit with `?PAPER`. Choose a position that leaves enough room for your drawing on the sheet.

Movement uses the existing motor driver and its usual temporary 220-byte reserve. Empty BASIC free RAM remains 5,951 bytes; all 37 tokens and 54 commands are retained. Studio **0.2.41** recognizes this ROM and maintains the same tracking during normal or instant printing.

This version also fixes the display for **RETURN without GOSUB**: the complete `?GOSUB/RETURN` message, followed by the line number, now has its own protected ROM string. Print errors correctly release the driver's state so another attempt can follow.

Head positioning was confirmed on hardware on **24 November 2026**. All **17 software reports** pass for this exact firmware hash: BASIC execution, memory, five boots with the maskROM, serial transfers, sound, graphics, games and keyboard shortcuts. The new checks include 2,600 key mappings and 64 motor transitions, plus the print origin after RUN. The [images, checksums and reports](../../firmware/0.4.101-dev/README.md#english) and French/English PDF manuals accompany the release.
