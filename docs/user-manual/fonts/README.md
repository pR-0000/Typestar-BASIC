# Police du manuel

Le PDF utilise Lato (Łukasz Dziedzic), en romain, gras, italique et gras italique. Les fichiers proviennent du dépôt officiel Google Fonts : https://github.com/google/fonts/tree/main/ofl/lato . Leur licence SIL Open Font License 1.1 figure dans OFL.txt. Ils sont embarqués pour rendre la construction du PDF indépendante des polices installées sur le système.

Le texte courant passe de 10 à 11,5 points ; tableaux et légendes sont également agrandis. Les couleurs brunes et les encadrés s’inspirent de la présentation du manuel Canon Typestar 7 sans en reproduire les pages.
